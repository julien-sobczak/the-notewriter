# Test Goto Links

## Note: Examples with placeholders

Here are some example goto links with different types of placeholders:

* [GitHub Repository](https://github.com/julien-sobczak/the-notewriter/ "#go/github")
* [GitHub Issues](https://github.com/julien-sobczak/the-notewriter/${page} "#go/github-page")
* [GitHub Section](https://github.com/julien-sobczak/the-notewriter/${section:[issues,pulls,actions]} "#go/github-section")
* [GitHub Custom](https://github.com/julien-sobczak/the-notewriter/${type:[issues,pulls,actions,...]} "#go/github-custom")
* [Multi Placeholder](https://github.com/${user}/${repo}/${section:[issues,pulls]} "#go/multi")
