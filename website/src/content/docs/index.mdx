<section class="faq">
  <h1 class="title">F.A.Q.</h1>

  <details>
    <summary><span class="handwritten-regular">Is</span> it okay if I use it? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>Yes, but no...<br/>I created _The NoteWriter_ to experiment with my note-taking approach. I reworked some features several times (and I still have ideas to try). Breaking changes are inevitable when experimenting.</p>
  </details>

  <details>
    <summary><span class="handwritten-regular">Why</span> another tool? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>I love reading and writing but I wasn't satisfied with my reading and writing workflow. I created _The NoteWriter_ to optimize my process. I didn't created it to have an open source project to showcase. My long-term goal is to write more using my readings as inspiration.</p>
  </details>

  <details>
    <summary><span class="handwritten-regular">Why</span> for developers? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>As a developer, I tried to reuse most of my knowledge. Git is more efficient to version my notes. Code editors are most efficient to enter text. No UI can compete with these tools. I introduced concepts familiar to developers — configuration files, templates, linter, hooks, remotes —  to have a powerful tool with a minimal codebase.</p>
  </details>

  <details>
    <summary><span class="handwritten-regular">Why</span> not use paper notes? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>Paper notes have obvious advantages. The pencil is one of the best human inventions, like the computer. Digital notebooks have drawbacks but also many advantages: you can insert notes between existing ones, delete without scribbles, copy URLs using shortcuts, etc. _The NoteWriter_ is designed to leverage these advantages while minimizing the drawbacks of not having a pencil in my hand.</p>
  </details>

  <details>
    <summary><span class="handwritten-regular">Why</span> is it open source? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>Working in public is a great way to share my reflection on the topic. I'm not looking for contributors. I designed the application to be maintainable by a solo developer (me) on my spare time. My goal is inspire others to reflect on their own note-taking process. We need more OSS tools designed for the long term like [SQLite](https://sqlite.org/lts.html).</p>
  </details>

  <details>
    <summary><span class="handwritten-regular">What</span> is the current status of the project? <Image class="question-mark" src={characterQuestion} alt="Question?" /></summary>
    <p>The CLI is relatively stable and well-tested.<br/>The desktop application is a work in progress. I continue to experiment a lot with it.<br/>The mobile application is still in its infancy. I have a clear idea of the goal and its limited scope but I prefer to focus on the desktop application for now.</p>
  </details>

</section>
