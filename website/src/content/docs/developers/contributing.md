---
title: Contributing
---

:::caution

I created _The NoteWriter_ for my personal use. You probably should not use it as long as I'm the only contributor. My goal is not to maintain a popular OSS project but to have the missing tool on which to build my long-lasting writing routine. I want to use my notes to be creative. _The NoteWriter_ is only the way towards that goal.

:::

Any feedback is welcome. You can reach me through [my blog](https://juliensobczak.com/).

If you share the same values behind _The NoteWriter_ and if you have reached the same conclusion concerning existing note-taking applications, you could give it a try as your notes are really yours when using _The NoteWriter_. Feel free to [open an issue](https://github.com/julien-sobczak/the-notewriter/issues) on GitHub to report bugs, improvements, ideas or [open a pull request](https://github.com/julien-sobczak/the-notewriter/pulls) to submit code changes.
