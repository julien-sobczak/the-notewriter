title: Introduction
---

This guide can be read in **less than 15 minutes** but that doesn't mean we'll only scratch the surface.

It's **an in-depth guide**. _The NoteWriter_ is a minimal application reusing knowledge and concepts that developers are already familiar with. You will discover all the features with concrete explanations of how things work and also how to configure the application to adapt to any creative process.

Most of the guide will focus on how to write notes. Commands using `nt` will be introduced in context. Before going further, make sure to have run `nt init` to have a repository to play with.
